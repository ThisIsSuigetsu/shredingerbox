# ShredingerBox

VPN-клиент для Windows на ядре [sing-box](https://github.com/SagerNet/sing-box).
Добавил подписку, нажал одну кнопку - подключено. Тонкая настройка спрятана в продвинутый режим.

**[Скачать последнюю версию](https://github.com/ThisIsSuigetsu/shredingerbox/releases/latest)** ·
[Как установить](FRIENDS.md) · [История версий](CHANGELOG.md)

## Возможности

**Подключение**
- Ключи `vless://` (Reality, TLS, ws, grpc, httpupgrade), `hy2://` (Salamander, диапазоны портов),
  `trojan://` и `ss://`.
- Подписки по ссылке `https://…` - base64 или список ключей, обновление одной кнопкой.
- Скопировал ключ или подписку - клиент сам предложит добавить их из буфера обмена.
- Два режима: **TUN** - весь трафик компьютера, **Прокси** - системный прокси Windows, без прав
  администратора.

**Серверы**
- Серверы сгруппированы по подпискам, ручные ключи - отдельно.
- Пинг каждого сервера реальным запросом через туннель, переключение без переподключения.
- Скорость загрузки и отдачи, таймер сессии.
- Расход трафика по каждому серверу за месяц.

**Правила**
- Выбранные приложения - через VPN или напрямую. Приложение можно выбрать из запущенных
  или указать `.exe`.
- Выбранные сайты - через VPN или напрямую. Списки можно вставлять целиком, по одному
  на строку. «Сайты напрямую» важнее всех остальных правил - удобно для банков и госуслуг.
- Готовые наборы сайтов: YouTube, Discord, Instagram, X, ChatGPT, Claude, Spotify.
- Весь остальной трафик - через VPN или напрямую, на выбор.

**Удобство**
- Живёт в трее. Иконки в трее и на панели задач показывают, включён ли VPN, а маскот спит
  или выглядывает из коробки.
- Автозапуск с Windows и автоподключение. TUN при этом работает без окна UAC.
- Автообновление через GitHub Releases.
- Напоминание о продлении подписки.

**Продвинутый режим** - порт прокси, доступ из локальной сети, DNS, уровень логов, итоговый
конфиг и логи ядра.

## Установка

Скачай `ShredingerBox_…_x64-setup.exe` со страницы
[Releases](https://github.com/ThisIsSuigetsu/shredingerbox/releases/latest) и запусти.
Права администратора для установки не нужны. Подробная инструкция - в [FRIENDS.md](FRIENDS.md).

Без установки - `ShredingerBox_…_x64-portable.zip`: распакуй куда угодно и запусти `ShredingerBox.exe`.
Пока рядом лежит `portable.txt`, настройки хранятся в папке `data` рядом с программой.

Есть сборка для macOS, но пока она экспериментальная: работает только режим «Прокси», без
автозапуска, и приложение не подписано сертификатом Apple - первый запуск через правый клик →
«Открыть».

## Разработка

Понадобятся:

- [Node.js LTS](https://nodejs.org)
- [Rust](https://rustup.rs) с MSVC-тулчейном
- [Microsoft C++ Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
  с компонентом «Разработка классических приложений на C++»
- WebView2 - уже есть в Windows 10 и 11

Запуск в режиме разработки - `start-dev.bat`. Он сам скачает ядро sing-box, поставит зависимости
и запустит приложение. Первая сборка Rust занимает 5-15 минут.

Режим TUN требует прав администратора, поэтому для его проверки запускай `start-dev.bat`
от имени администратора.

Вручную то же самое:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\get-sing-box.ps1
npm install
npm run tauri dev
```

Локальная сборка установщика - `build-release.bat`, результат появится в
`src-tauri\target\release\bundle\nsis\`.

Тесты разбора ссылок и сборки конфига:

```powershell
cd src-tauri
cargo test
```

Выпуск новой версии через GitHub - `release.bat`, подробности в [RELEASING.md](RELEASING.md).

### Устройство проекта

```
src/                 интерфейс: TypeScript и CSS без фреймворков
  main.ts            экраны, обработчики, связь с Rust
  styles.css         тёмная тема
  mascot.ts          маскот, он же иконка
src-tauri/src/
  lib.rs             команды для интерфейса, запуск приложения
  links.rs           разбор ключей и подписок в outbound sing-box
  config.rs          сборка конфига sing-box из настроек
  core.rs            запуск и остановка sing-box, логи
  system.rs          права администратора, системный прокси, список процессов
  settings.rs        файл настроек
  presets.rs         готовые наборы сайтов
scripts/             загрузка ядра, выпуск версии
```

Настройки, итоговый `config.json` и кэш ядра хранятся в `%APPDATA%\org.shredingerbox.app\`.
Открыть эту папку можно кнопкой «Папка данных» в настройках.
