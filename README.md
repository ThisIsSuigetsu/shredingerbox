# ShredingerBox

Простой VPN-клиент для Windows на ядре [sing-box](https://github.com/SagerNet/sing-box).
Одна кнопка для друзей, всё сложное — в продвинутом режиме.

Лицензия: GPL-3.0-or-later (как у Throne, из которого можно переносить логику).

## Что умеет

### 0.5

- Автообновление через GitHub Releases: клиент сам находит новую версию, останавливает ядро,
  ставит обновление и перезапускается. Отключается в настройках.
- GitHub Actions собирает Windows и macOS по метке `v*` — см. `RELEASING.md`.
- `release.bat` — выпуск новой версии одной командой.

### 0.4

- Вставка из буфера: скопировал ключ или ссылку подписки — открыл клиент — он предложит добавить.
  Буфер читается в Rust, в интерфейс попадают только ключи и ссылки подписок. Отключается в настройках.
- Установщик для текущего пользователя на русском, без прав администратора при установке.
- `FRIENDS.md` — инструкция для друзей.

### 0.3

- Только одна копия: повторный запуск показывает окно уже работающего клиента.
- Иконка в трее меняется: серая коробка — VPN выключен, мятная — включён.
- Все серверы сразу в ядре: пинг каждого через туннель и мгновенное переключение без перезапуска.

### 0.2

- Трей: подключение и выход из меню, клик по иконке открывает окно.
- Крестик сворачивает в трей (отключается в настройках).
- Автозапуск с Windows через планировщик задач — сразу с правами администратора, TUN без UAC.
  Перезапуск «с правами» тоже идёт через эту задачу без окна UAC.
- Автоподключение при автозапуске.
- Экран «Серверы»: группы по подпискам, удаление подписки, ручные ключи отдельно.
- Пинг через ядро (реальный запрос через VPN) для выбранного сервера, пока VPN включён.
- Напоминание о продлении подписки 20-го числа.

### 0.1

- Ключи `vless://` (Reality, TLS, ws/grpc/httpupgrade), `hy2://` (в том числе Salamander и диапазоны портов), `trojan://`, `ss://`.
- Подписки по ссылке `https://…` (base64 или список ссылок), обновление одной кнопкой.
- Режимы **TUN** (весь трафик, нужны права администратора) и **Прокси** (системный прокси Windows).
- Правила: приложения через VPN / напрямую, сайты через VPN, готовые наборы (YouTube, Discord и др.), «остальной трафик» через VPN или напрямую.
- Выбор приложения из запущенных программ или через «Выбрать .exe».
- TCP-пинг серверов, скорость загрузки/отдачи и таймер сессии.
- Продвинутый режим: порт прокси, доступ из локальной сети, DNS, уровень логов, просмотр итогового конфига и логов ядра.

## Подготовка (один раз)

1. **Node.js LTS** — https://nodejs.org
2. **Rust** — https://rustup.rs (при установке согласись на MSVC-тулчейн).
3. **Microsoft C++ Build Tools** — https://visualstudio.microsoft.com/visual-cpp-build-tools/
   В установщике отметь «Разработка классических приложений на C++».
4. **WebView2** уже есть в Windows 10/11.
5. **Ядро sing-box версии 1.12 или новее** — см. `src-tauri/binaries/README.md`.

## Запуск

```powershell
npm install
npm run tauri dev
```

Режим TUN требует прав администратора. В dev-режиме проще всего открыть терминал
«от имени администратора» и запускать оттуда. В собранной версии клиент сам
предложит перезапуститься с правами.

## Сборка установщика

```powershell
npm run tauri build
```

Установщик появится в `src-tauri/target/release/bundle/nsis/`.

## Устройство проекта

```
src/                 интерфейс (TypeScript + CSS, без фреймворков)
  main.ts            экраны, обработчики, связь с Rust
  styles.css         тёмная тема по макету
  mascot.ts          маскот (он же иконка)
src-tauri/src/
  lib.rs             команды для интерфейса, запуск приложения
  links.rs           разбор ссылок и подписок → outbound sing-box (+ тесты)
  config.rs          сборка конфига sing-box из настроек (+ тесты)
  core.rs            запуск/остановка sing-box, логи
  system.rs          права администратора, системный прокси, список процессов
  settings.rs        settings.json
  presets.rs         готовые наборы доменов
```

Настройки, итоговый `config.json` и кэш ядра лежат в `%APPDATA%\org.shredingerbox.app\`
(кнопка «Папка данных» в настройках).

Тесты логики ссылок и конфига: `cd src-tauri && cargo test`.
