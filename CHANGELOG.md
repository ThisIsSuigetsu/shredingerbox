# История версий

## 0.5.1

- Обновлены README и история версий. Изменений в работе клиента нет — выпуск проверяет автообновление
  с 0.5.0.

## 0.5.0

- Автообновление через GitHub Releases: клиент сам находит новую версию, останавливает ядро,
  ставит обновление и перезапускается. Отключается в настройках.
- Сборка Windows и macOS в GitHub Actions по метке `v*`.
- `release.bat` — выпуск новой версии одной командой.

## 0.4.0

- Вставка из буфера: скопировал ключ или ссылку подписки, открыл клиент — он предложит добавить.
  Буфер читается в Rust, в интерфейс попадают только ключи и ссылки подписок. Отключается в настройках.
- Установщик на русском для текущего пользователя, без прав администратора.
- `FRIENDS.md` — инструкция по установке.

## 0.3.0

- Запускается только одна копия: повторный запуск показывает окно уже работающего клиента.
- Иконка в трее показывает состояние: серая — VPN выключен, мятная — включён.
- Все серверы сразу загружаются в ядро: пинг каждого через туннель и мгновенное переключение
  без перезапуска.

## 0.2.0

- Трей: подключение и выход из меню, клик по иконке открывает окно.
- Крестик сворачивает в трей (отключается в настройках).
- Автозапуск с Windows через планировщик задач, сразу с правами администратора — TUN без окна UAC.
  Перезапуск с правами тоже идёт через эту задачу.
- Автоподключение при автозапуске.
- Экран «Серверы»: группы по подпискам, удаление подписки, ручные ключи отдельно.
- Пинг выбранного сервера реальным запросом через VPN.
- Напоминание о продлении подписки 20-го числа.

## 0.1.0

- Ключи `vless://` (Reality, TLS, ws/grpc/httpupgrade), `hy2://` (Salamander, диапазоны портов),
  `trojan://`, `ss://`.
- Подписки по ссылке `https://…` (base64 или список ссылок), обновление одной кнопкой.
- Режимы TUN и «Прокси».
- Правила для приложений и сайтов, готовые наборы, выбор «остального трафика».
- TCP-пинг серверов, скорость и таймер сессии.
- Продвинутый режим: порт прокси, доступ из локальной сети, DNS, уровень логов, итоговый конфиг
  и логи ядра.
