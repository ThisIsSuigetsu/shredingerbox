# История версий

## 0.9.1

- macOS: автозапуск. «Настройки» → «Запускать при входе в macOS» - клиент стартует в строке меню
  без окна и, если включено «Подключаться при автозапуске», сразу включает VPN.
- Незначительные исправления.

## 0.9.0

- Подписки обновляются сами: при запуске клиента и раз в 12 часов. Новые и изменённые серверы
  появляются без кнопки «Обновить». Интервал меняется в продвинутом режиме → «Подписки».
- Остаток трафика и срок подписки на экране «Серверы», если панель их сообщает. Название подписки
  тоже берётся из панели.
- Напоминание о продлении может срабатывать за 3 дня до конца подписки, а не в день месяца.
- «Авто» в списке серверов: ядро само выбирает сервер с наименьшей задержкой и переключается,
  если текущий перестал отвечать. По умолчанию выключено.
- Если одна подписка не загрузилась, остальные всё равно обновляются.
- Сборка надёжнее: версия ядра sing-box закреплена и сверяется по контрольной сумме, а шаги сборки
  на GitHub закреплены по конкретным коммитам.

## 0.8.1

- Язык и тема меняются сразу. VPN больше не переподключается при смене языка, темы, трея,
  напоминания и настроек загрузки подписок.
- Незначительные исправления.

## 0.8.0

- Английский язык. По умолчанию язык как в системе, в настройках можно выбрать «Русский» или «English».
  Переведены интерфейс, меню трея и сообщения об ошибках.
- Продвинутый режим разбит на вкладки: «Основное», DNS, TUN, «Маршрутизация» и «Подписки».
  - DNS: DoH, DoT или обычный UDP для VPN-трафика, свой DNS для сайтов напрямую, выбор IPv4 и IPv6.
  - TUN: сетевой стек, MTU, строгая маршрутизация, IPv6.
  - Маршрутизация: определение сайта по соединению, локальная сеть напрямую, блокировка QUIC,
    списки IP-адресов и подсетей через VPN и напрямую.
  - Подписки: автообновление по расписанию, свой User-Agent, переименование подписок.
- Проверка сервисов: кнопка «Сервисы» на главной показывает, открываются ли YouTube, Discord,
  ChatGPT, Claude и другие через текущее подключение и твои правила.
- Экспорт и импорт настроек: серверы, подписки и правила в одном файле - удобно перенести
  на другой компьютер.
- Напоминание о продлении подписки теперь можно настроить: число месяца и свой текст.
  Если напоминание уже было включено, оно работает как раньше.

## 0.7.0

- Светлая тема. В настройках можно выбрать: «Как в системе», «Тёмная» или «Светлая».
  По умолчанию тема следует за Windows или macOS.
- macOS: режим TUN - весь трафик Mac через VPN, как в Windows. При подключении macOS спрашивает
  пароль администратора, отключение - без пароля. По умолчанию на Mac по-прежнему «Прокси».

## 0.6.1

- Portable-версия для Windows: `ShredingerBox_…_x64-portable.zip` рядом с установщиком в каждом
  релизе. Распакуй куда угодно и запусти - все настройки хранятся в папке `data` рядом с программой.
- Окно обновления показывает, что изменилось в новой версии, а после обновления один раз
  появляется окно «Что нового».
- Незначительные исправления.

## 0.6.0

- Сайты - как приложения: список строками и окно «Добавить сайты», куда можно вставить сразу
  целый список, по одному на строку. Ссылки, `www.` и `*.` чистятся сами, дубликаты пропускаются,
  кириллические домены (`госуслуги.рф`) работают.
- Новая вкладка «Сайты напрямую». Эти сайты всегда идут мимо VPN - даже из приложений
  «через VPN» и готовых наборов. Удобно для банков и госуслуг. Сайт не может быть
  в обоих списках сразу.
- Длинные списки приложений и сайтов показывают первые 10 строк, остальное - в окне
  «Показать все» с поиском.
- Расход трафика по каждому серверу за месяц: на экране «Серверы» рядом с каждым сервером
  и на главной у текущего. Подсказка показывает загрузку и отдачу отдельно. Счётчик
  обнуляется 1-го числа.
- Серверы из подписки сохраняют свой id при обновлении подписки - выбор и статистика
  больше не теряются.
- macOS: приложение подписывается ad-hoc, и macOS больше не называет скачанный DMG «повреждённым».
  Инструкция для Mac - в `FRIENDS.md`.
- macOS: VPN наконец заводится. Раньше по умолчанию стоял режим TUN, которого на Mac нет, и ядро
  падало. Теперь на Mac сразу «Прокси», а системный прокси включается и выключается по-настоящему -
  на всех активных подключениях (Wi-Fi, Ethernet). Настройки, которые есть только в Windows, на Mac
  спрятаны.
- Если системный прокси не удалось включить, ядро останавливается и показывается понятная ошибка,
  а не висит без дела.

## 0.5.2

- Маскот показывает состояние VPN: спит в коробке, когда VPN выключен, выглядывает, когда включён,
  и подмигивает, пока идёт подключение.
- Иконка на панели задач тоже меняется: спящий или выглядывающий маскот, а при подключении -
  мятная точка поверх кнопки (видна и у закреплённого ярлыка).
- Иконка в трее теперь обновляется всегда: после смены режима или сервера, при неудачном
  перезапуске и при падении ядра, даже если окно спрятано в трей.

## 0.5.1

- Обновлены README и история версий. Изменений в работе клиента нет - выпуск проверяет автообновление
  с 0.5.0.

## 0.5.0

- Автообновление через GitHub Releases: клиент сам находит новую версию, останавливает ядро,
  ставит обновление и перезапускается. Отключается в настройках.
- Сборка Windows и macOS в GitHub Actions по метке `v*`.
- `release.bat` - выпуск новой версии одной командой.

## 0.4.0

- Вставка из буфера: скопировал ключ или ссылку подписки, открыл клиент - он предложит добавить.
  Буфер читается в Rust, в интерфейс попадают только ключи и ссылки подписок. Отключается в настройках.
- Установщик на русском для текущего пользователя, без прав администратора.
- `FRIENDS.md` - инструкция по установке.

## 0.3.0

- Запускается только одна копия: повторный запуск показывает окно уже работающего клиента.
- Иконка в трее показывает состояние: серая - VPN выключен, мятная - включён.
- Все серверы сразу загружаются в ядро: пинг каждого через туннель и мгновенное переключение
  без перезапуска.

## 0.2.0

- Трей: подключение и выход из меню, клик по иконке открывает окно.
- Крестик сворачивает в трей (отключается в настройках).
- Автозапуск с Windows через планировщик задач, сразу с правами администратора - TUN без окна UAC.
  Перезапуск с правами тоже идёт через эту задачу.
- Автоподключение при автозапуске.
- Экран «Серверы»: группы по подпискам, удаление подписки, ручные ключи отдельно.
- Пинг выбранного сервера реальным запросом через VPN.
- Напоминание о продлении подписки 20-го числа.

## 0.1.0

- Ключи `vless://` (Reality, TLS, ws/grpc/httpupgrade), `hy2://` (Salamander, диапазоны портов),
  `trojan://`, `ss://`.
- Подписки по ссылке `https://…` (base64 или список ссылок), обновление одной кнопкой.
- Режимы TUN и «Прокси».
- Правила для приложений и сайтов, готовые наборы, выбор «остального трафика».
- TCP-пинг серверов, скорость и таймер сессии.
- Продвинутый режим: порт прокси, доступ из локальной сети, DNS, уровень логов, итоговый конфиг
  и логи ядра.
