# Ядро sing-box

Сюда кладётся `sing-box.exe` для Windows, переименованный под формат Tauri:

```
sing-box-x86_64-pc-windows-msvc.exe
```

1. Скачай свежий релиз `sing-box-<версия>-windows-amd64.zip` со страницы
   https://github.com/SagerNet/sing-box/releases
2. Достань из архива `sing-box.exe`.
3. Переименуй его в `sing-box-x86_64-pc-windows-msvc.exe` и положи в эту папку.

Tauri сам упакует его в установщик и положит рядом с ShredingerBox.exe.
